# Карточка товара «Ананасовый улун»

Вёрстка верхней части карточки товара для teaboom.ru. Без фреймворков: чистый HTML, CSS, JS.

## Запуск

Двойной клик по `index.html` → открывается в браузере по протоколу `file://`.


## Брейкпоинты адаптива

| Устройство | Ширина    |
|------------|-----------|
| Desktop    | > 960 px  |
| Tablet     | ≤ 960 px  |
| Mobile     | ≤ 560 px  |
